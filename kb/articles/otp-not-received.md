# One-time password (OTP) not received

## Common causes
- SMS delays from the mobile operator, especially when roaming outside Bahrain.
- The registered mobile number is outdated.
- Too many requests: OTP resend is limited to 3 times per 10 minutes.

## What the customer can check
1. Confirm the registered number shown (masked) on the OTP screen.
2. Wait 2 minutes before requesting a new code; each new code invalidates the previous one.
3. When roaming, enable roaming SMS or use in-app push approval instead of SMS.

## Changing the registered number
- A mobile number change requires a branch visit or video KYC; agents cannot change it over chat.
- After a number change, OTPs go to the new number within 1 hour.
